# FreeYou — React Native

אפליקציית גמילה מפורנוגרפיה ומגלילה כפייתית, עם חסימה אמיתית ברמת מערכת ההפעלה.

---

## התקנה

```bash
bash setup.sh
cd ../FreeYouApp
npx react-native run-android
```

זהו. הסקריפט יוצר שלד React Native 0.74.5 תקין, מתקין את התלויות, מרכיב לתוכו את כל
קוד FreeYou, ומתקן את ה-`applicationId` ואת `minSdk`. אין שלבים ידניים ואין קבצים לערוך.

> **סגור ופתח את האפליקציה פעם אחת** אחרי ההתקנה הראשונה — `I18nManager.forceRTL`
> נכנס לתוקף רק בהרצה הבאה. זו הפעם היחידה שתראה פריסה הפוכה.

אחרי שהאפליקציה עולה: מסך "חוסם" יראה כרטיס אדום עם שני כפתורים להרשאות. עד שתאשר
אותם, החומה לא חוסמת כלום — האפליקציה אומרת את זה במפורש במקום להעמיד פנים.

### גופנים (אופציונלי)
האפליקציה רצה מיד עם גופן המערכת. לטיפוגרפיה המלאה — הורד מ-Google Fonts את
`Rubik-Bold`, `Rubik-Black`, `Assistant-Regular`, `Assistant-SemiBold`, הנח ב-
`android/app/src/main/assets/fonts/`, ושנה ב-`src/theme.ts`:

```ts
export const CUSTOM_FONTS = true;
```

## איך החסימה עובדת בפועל

| שכבה | קובץ | תפקיד |
|---|---|---|
| זיהוי | `BlockerAccessibilityService.kt` | קורא את שורת הכתובת של הדפדפן ואת האפליקציה בחזית, ועוצר לפני שהתוכן נטען |
| כללים | `BlockRepo.kt` | רשימה ידנית + רשימת דומיינים ציבורית, כולל תת־דומיינים |
| צלצול | `AlarmService.kt` | שירות חזית — ממשיך גם כשסוגרים את האפליקציה, עוקף מצב שקט, פותח מסך נעול |
| נעילה | `AdminReceiver.kt` | מונע הסרת האפליקציה כשמצב קפדני פעיל |
| ניתוב | `BlockerModule.kt` | מעביר את אירוע החסימה ל-JS, וגם שומר יעד בדיסק כדי שפתיחה קרה של האפליקציה תדע לאן ללכת |

**למה שירות נגישות ולא VPN:** גישת ה־VPN חוסמת ברמת DNS, אבל נשברת מול DNS־over־HTTPS
(ברירת המחדל ב־Chrome היום) ומול VPN אחר שהמשתמש מפעיל. שירות נגישות רואה את הכתובת עצמה
בשורת הכתובת, ולכן עובד גם בגלישה פרטית וגם כש־DoH פעיל. זו הסיבה שכל אפליקציות החסימה
הרציניות באנדרואיד עובדות ככה.

**רשימת הדומיינים** מגיעה מ־StevenBlack/hosts (הווריאנט porn) — מתוחזקת, ציבורית, ומתעדכנת
בלחיצה מתוך מסך החוסם. אפשר להחליף ל־OISD NSFW ב־`ShieldScreen.tsx`.

### על ביצועים
`@react-native-community/blur` בתוך רשימה נגללת גורם לקפיצות באנדרואיד. לכן ב-`Glass.tsx`
יש דגל `live`: הטשטוש האמיתי שמור לדוק, לפנס ולשכבות המלאות — אלמנטים סטטיים שבהם רואים
את ההבדל. הכרטיסים משתמשים בשכבות צבע שמשחזרות את אותו מראה בעלות אפס. אם תרצה טשטוש
בכל מקום, הוסף `live` לכל `<Glass>` — זה ייראה זהה כמעט, ויגלול פחות חלק.

## המנטור הקולי

- **שמיעה:** `@react-native-voice/voice` עם `he-IL` — מנוע Google, מגיע עם רוב מכשירי אנדרואיד.
- **דיבור:** `react-native-tts`. הקול העברי המובנה סביר אבל מכני. לקול אנושי באמת —
  החלף ב־ElevenLabs (`eleven_multilingual_v2` תומך בעברית טוב) והשמע דרך `react-native-sound`.
- **מוח:** `src/mentor.ts`.

### חובה: פרוקסי, לא מפתח באפליקציה
מפתח API בתוך APK אפשר לחלץ בשתי דקות. הרם Cloudflare Worker:

```js
export default {
  async fetch(req, env) {
    if (req.method !== 'POST') return new Response('no', {status: 405});
    const body = await req.json();
    const r = await fetch('https://api.anthropic.com/v1/messages', {
      method: 'POST',
      headers: {
        'content-type': 'application/json',
        'x-api-key': env.ANTHROPIC_API_KEY,
        'anthropic-version': '2023-06-01',
      },
      body: JSON.stringify(body),
    });
    return new Response(r.body, {headers: {'content-type': 'application/json'}});
  },
};
```

`wrangler secret put ANTHROPIC_API_KEY`, ואז עדכן את `PROXY` ב־`src/mentor.ts`.

## על iOS

החסימה הזו לא ניתנת למימוש ב־iOS. אין שם מקבילה לשירות נגישות, ו־`FamilyControls` / `ManagedSettings`
מאפשרים רק חסימה ברמת קטגוריה — ודורשים אישור מיוחד מאפל שניתן בעיקר לאפליקציות בקרת הורים.
מה שכן אפשר: DNS Profile + Screen Time. הצד הצרכני (מנטור, יומן, שיעורים) עובר ל־iOS כמו שהוא.

## מה נלקח מסקיצת ה-Flutter

| רעיון | איפה זה בקוד |
|---|---|
| זוהר רך במקום עיגול צבע | `Mesh.tsx` — RadialGradient ב-SVG. ל-RN אין `filter: blur` על View, אז עיגול עם opacity יוצא עם קצה חד. הגרדיאנט הרדיאלי נותן את הזוהר שהסקיצה כיוונה אליו |
| הילה סביב הלהבה | `HomeScreen.tsx` — ההילה מתחזקת ככל שהכדור מתמלא |
| גבול צבעוני לכל כרטיס | `Glass.tsx` — הוספתי `glow`. הצבע מקודד קטגוריה: ורוד=חירום, סגול=מנטור, תכלת=לימוד, ליים=חומה |
| משימת היום על מסך הבית | `HomeScreen.tsx` — הייתה קבורה בטאב "בנייה". זו הפעולה היחידה שיש לו לעשות היום, אז היא במסך הראשון |
| מיקרופון צף | `App.tsx` — המנטור במרחק נגיעה מכל מסך, לא רק מהטאב שלו |
| חיווי האזנה | `MentorScreen.tsx` — חמישה פסים שנעים במקום כפתור שרק מחליף צבע |

## שלוש החלטות שכדאי שתכיר

**1. מצב לילה בטוח (ברירת מחדל: פעיל).** בין 23:00 ל־05:00 משימת הריצה הופכת לפרוטוקול ביתי
של 12 דקות. אפשר לכבות במסך "אני". הסיבה: ענישה מייצרת בושה, ובושה היא המנבא החזק ביותר
לנפילה הבאה. משימה קשה — כן. משהו שיגרום לך למחוק את האפליקציה בשבוע השני — לא.

**2. כפתור חירום שתמיד פתוח.** מסך ה־SOS והמנטור לא ננעלים גם במצב קפדני. אף פעם לא נועלים
החוצה בן אדם שצריך עזרה.

**3. מודול "קשר ואומץ חברתי"** בנוי סביב נוכחות, סקרנות וכבוד — לא סביב טכניקות.
אובייקטיפיקציה היא בדיוק המנגנון שאתה נגמל ממנו; אפליקציה שמלמדת אותה תסתור את עצמה.

## חנות Play

שירות נגישות + Device Admin הם הרשאות רגישות. תצטרך:
- טופס Permissions Declaration עם הסבר מדויק לשימוש
- **סרטון הדגמה** של הזרימה מקצה לקצה (זה מה שבדרך כלל תוקע אישורים)
- מדיניות פרטיות שמצהירה שכתובות אתרים לא יוצאות מהמכשיר

לשימוש אישי או למעגל קרוב — `npm run build:release` ו־APK ישיר, בלי חנות.
